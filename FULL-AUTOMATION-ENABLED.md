
### Database Queries
```sql
-- Check today's article count
SELECT COUNT(*) FROM articles
WHERE created_at > CURRENT_DATE;

-- View recent articles
SELECT title, category, quality_score, created_at
FROM articles
ORDER BY created_at DESC
LIMIT 10;

-- SEO performance
SELECT
  COUNT(*) as total,
  AVG(seo_score) as avg_score,
  COUNT(*) FILTER (WHERE seo_optimized) as optimized
FROM articles;

-- Social media stats
SELECT
  COUNT(*) FILTER (WHERE social_promoted) as promoted,
  SUM(social_post_count) as total_posts
FROM articles;
```

### Control Commands
```bash
# Pause automation
pm2 stop autonomous-orchestrator

# Resume automation
pm2 restart autonomous-orchestrator

# View detailed status
pm2 show autonomous-orchestrator

# Check logs
pm2 logs autonomous-orchestrator --lines 100
```

## 🚨 Troubleshooting

### If articles aren't generating:
```bash
# Check orchestrator logs
pm2 logs autonomous-orchestrator --err

# Test content generation manually
npm run test:content

# Verify database connection
node test-database.js

# Check API key
echo $ANTHROPIC_API_KEY
```

### If schedules aren't running:
```bash
# Verify tasks are registered
pm2 logs autonomous-orchestrator | grep "Registered"

# Check Redis connection
redis-cli ping

# Restart orchestrator
pm2 restart autonomous-orchestrator
```

### If database issues:
```bash
# Test connection
psql -U scholarnet_user -d scholarnet -h localhost -c "SELECT 1"

# Check disk space
df -h

# Verify tables exist
psql -U scholarnet_user -d scholarnet -h localhost -c "\dt"
```
