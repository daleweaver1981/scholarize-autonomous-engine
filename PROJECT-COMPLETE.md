## 🚀 Quick Start (Production)

```bash
# 1. Clone/copy to server
cd /opt
git clone [your-repo] scholarnet-autonomous-engine
cd scholarnet-autonomous-engine

# 2. Install dependencies
npm install
npm install pg

# 3. Setup database
sudo -u postgres psql scholarnet < database/schema.sql

# 4. Configure environment
cp .env.example .env
nano .env  # Add your API keys

# 5. Start with PM2
npm run orchestrator:start

# 6. Verify
pm2 status
pm2 logs scholarnet-orchestrator

# 7. Monitor
pm2 monit
```

**That's it! Your autonomous engine is now running!** 🎉
